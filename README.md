
# Multi-Agent Task Automation System

A Python project to build an AI-powered system that decomposes
complex tasks, coordinates specialized agents, and produces
structured results.

## Planned Features

- Task planning and orchestration
- Specialized AI agents
- Tool and API integration
- Task execution and result verification
- Web interface and persistent storage

## Technology Stack

- Python
- LangGraph
- LLM API
- FastAPI
- Streamlit
- Git and GitHub
